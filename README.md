## Proyecto académico: Lava Rápido Vehicular

Proyecto en equipo para gestionar servicios de lavado, vehículos, reservas, operadores y pagos. Trabajamos con una API REST en Java 17 y Spring Boot, PostgreSQL y Liquibase para los datos, React y Vite para el panel web, y React Native con Expo para la aplicación móvil. Participé en análisis, desarrollo, integración y pruebas.
